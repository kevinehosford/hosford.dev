### Overview
Two more local checks that weren't checking what they said. On auth, the MCP org choice moved onto the consent screen. Threads runs got one trace end to end.

### Highlights
- [#8921](https://github.com/axiomhq/ctrl/pull/8921), [#8932](https://github.com/axiomhq/ctrl/pull/8932) — The console's Tailwind CSS contract check had been failing on main for five days while GitHub stayed green, because no workflow runs it. Fixed the two stacked breakages, then closed two holes that let the check pass without exercising the matching it guards, each one shown with a mutation probe. Separately, with a warm cache and a deliberately broken file on disk, `agent:lint` reported 20 of 20 cached and successful: the task hash covered only the console's own files while its steps read shared packages too. It hashes everything it reads now.
- [#8923](https://github.com/axiomhq/ctrl/pull/8923), [#8898](https://github.com/axiomhq/ctrl/pull/8898), [axiomhq/mcp#140](https://github.com/axiomhq/mcp/pull/140) — The MCP worker's own org picker goes away with its OAuth server, so the choice of which org an MCP client is for moved to the AuthKit consent screen, and a failed user lookup during that flow fails in a way the client can retry. On the MCP side the worker is a resource server that serves protected-resource metadata, so clients can find where to authorize (merged in September).
- [#9036](https://github.com/axiomhq/ctrl/pull/9036), [axiomhq/axiom#18659](https://github.com/axiomhq/axiom/pull/18659) — A Threads run used to produce disconnected traces across the console, the workers and the sandbox. Now one submission is one trace through every hop, and the v1 and v2 API servers honor the client's trace context so the API's spans join it.
- [axiomhq/repobeats#87](https://github.com/axiomhq/repobeats/pull/87) — GitHub started sending the RFC 9207 `iss` parameter on OAuth callbacks, which the older `openid-client` on repobeats validates and didn't have configured. Sorted that out so GitHub login completes.
- [#8899](https://github.com/axiomhq/ctrl/pull/8899) — The env lint rule validates the values the schema knows about instead of flagging every `.env` key missing from it. Agent worktrees symlink a real `.env`, so they were failing lint on branches that never touched env config.
