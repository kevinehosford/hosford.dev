### Overview
Build and deploy week. One console build now serves every deploy target instead of each workflow building cold, deploy checkouts got cheaper, and the auth app started shipping traces.

### Highlights
- [#8406](https://github.com/axiomhq/ctrl/pull/8406), [#8407](https://github.com/axiomhq/ctrl/pull/8407), [#8408](https://github.com/axiomhq/ctrl/pull/8408) — `vercel build` wasn't going through Turbo, so every deploy workflow rebuilt from cold: four full builds per commit. Routed it through turbo and removed the build-time env couplings that would have split the cache key, so all five targets share one hash. A cached production build went from 23.8s to 837ms locally. Two follow-ups the same day, because Vercel's restored build cache keeps `node_modules` for packages that no longer exist and the install-time package builds tripped over them, so those builds are skipped on Vercel.
- [#8409](https://github.com/axiomhq/ctrl/pull/8409), [#8411](https://github.com/axiomhq/ctrl/pull/8411), [#8388](https://github.com/axiomhq/ctrl/pull/8388) — Staging and production deploy jobs were checking out full history plus LFS on a repo with no LFS files, 93s against 15s for the dev deploy on the same commit. Gave them the same shallow blob-less checkout. Skipped the agent tooling install in CI, which was cloning three repos in every job. Production EU deploys are dispatch-only now, ahead of the legacy EU console going away on 1 September.
- [#8389](https://github.com/axiomhq/ctrl/pull/8389), [#8395](https://github.com/axiomhq/ctrl/pull/8395), [#8398](https://github.com/axiomhq/ctrl/pull/8398) — The auth app initializes tracing from a nitro plugin, since Vercel's output never loads the `--import` file the dev script used. Sign-in events carry the org and flow in the cases that were missing them. Upgraded the AuthKit SDKs.
- [#8391](https://github.com/axiomhq/ctrl/pull/8391) — Trace lookup by ID unions every trace-shaped dataset into one query, which the backend refuses when system and user datasets are mixed. Chunked the union so they're queried separately.
