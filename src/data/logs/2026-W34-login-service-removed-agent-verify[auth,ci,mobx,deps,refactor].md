### Overview
Deleted the legacy login service. Made the local pre-push check run what CI runs, after it turned out it had been skipping packages and reporting green. Split a big MobX store removal into one PR per store and cleaned up dependencies.

### Highlights
- [axiomhq/axiom#18510](https://github.com/axiomhq/axiom/pull/18510) — Removed the login service. Auth is on WorkOS, nothing builds or deploys the old service anymore, so out it went: 11,105 lines deleted.
- [#8796](https://github.com/axiomhq/ctrl/pull/8796) — Code Quality had failed 16 times on my PRs in two weeks, and seven of those were in `apps/auth`, where no local `agent:` command could have caught them. Turbo only runs a task in packages that declare it, so the local check ran in 17 packages, skipped the rest and still came back green. Added `pnpm agent:verify`, one command that runs what CI runs, and checked it by injecting each kind of failure and watching it get caught.
- [#8807](https://github.com/axiomhq/ctrl/pull/8807), [#8795](https://github.com/axiomhq/ctrl/pull/8795) — The auth app serves OAuth 2.0 authorization server metadata, so the CLI and other OAuth clients can discover its endpoints instead of having them hardcoded. The console resolves the WorkOS session once per request and passes it down, since refresh tokens rotate on use and six separate call sites were each resolving it.
- [#8810](https://github.com/axiomhq/ctrl/pull/8810), [#8808](https://github.com/axiomhq/ctrl/pull/8808), [#8833](https://github.com/axiomhq/ctrl/pull/8833), [#8839](https://github.com/axiomhq/ctrl/pull/8839), [#8876](https://github.com/axiomhq/ctrl/pull/8876) — One store per PR: `ConnectStore`, `StripeStore`, `InitQueryStore`, `PlayStore` and `UsersStore` come off MobX onto react-query or plain React. They started as one PR, split so each could be QA'd on its own.
- [#8838](https://github.com/axiomhq/ctrl/pull/8838), [#8832](https://github.com/axiomhq/ctrl/pull/8832), [#8842](https://github.com/axiomhq/ctrl/pull/8842), [#8873](https://github.com/axiomhq/ctrl/pull/8873), [#8834](https://github.com/axiomhq/ctrl/pull/8834), [#8835](https://github.com/axiomhq/ctrl/pull/8835) — Dependency cleanup. Dropped `better-auth` (nothing imports it since the WorkOS move) and `react-spring`, moved `swagger-typescript-api` to v13, which is a breaking codegen change so it got its own PR, synced swagger from the API repo, and removed a root `Dockerfile` that built a layout that no longer exists.
- [#8871](https://github.com/axiomhq/ctrl/pull/8871), [#8762](https://github.com/axiomhq/ctrl/pull/8762), [#8824](https://github.com/axiomhq/ctrl/pull/8824), [#8828](https://github.com/axiomhq/ctrl/pull/8828), [#8864](https://github.com/axiomhq/ctrl/pull/8864), [#8879](https://github.com/axiomhq/ctrl/pull/8879) — Two tests in the UI package had been red on main for 11 days because CI doesn't run that suite; updated them for the Tailwind 4 spacing scale. The query form infers MPL vs APL from the query text at submit, so pasting MPL before the dataset list loads doesn't send it as APL. The dataset limit stops counting views. Token creation no longer drops the submit when a capability isn't served. Switching accounts recovers when the URL still points at the previous account's org. Log stream widgets respect the dashboard filter bar.
