### Overview
Chased out-of-memory failures on dashboard pages down to a four-line fix, started the auth migration by lifting the WorkOS-based auth app into the monorepo, and removed classy-forms and the edge-querying flag. Also moved to pnpm 11.

### Highlights
- [#8086](https://github.com/axiomhq/ctrl/pull/8086) — Dashboard pages were running out of memory. A heap snapshot of a production build showed one array type holding nearly all of the heap: MobX was deep-observing every dataset's field schema, which a recent change had started carrying on each dataset. Switched three fields to reference observation. +4/−4.
- [#8105](https://github.com/axiomhq/ctrl/pull/8105), [#8154](https://github.com/axiomhq/ctrl/pull/8154) — Phase 1 of the auth migration: ported the WorkOS-based `apps/auth` from `ctrl-legacy` into the monorepo along with the packages it depends on. Purely additive, the console stays on its existing login for now. Then took the app off Vercel Microfrontends so it deploys as its own project on its own subdomain, which gets it independent deploys and drops the `/login` prefix that was baked into every route.
- [#8104](https://github.com/axiomhq/ctrl/pull/8104), [#8131](https://github.com/axiomhq/ctrl/pull/8131) — Removed `classy-forms` (ported the two date menus that still used it to react-hook-form, 33 files, +566/−2128) and the `fe-edge-querying` flag plumbing. The flag had been on in production for a while, so about 60 call sites lose a parameter and always take the edge path.
- [#8124](https://github.com/axiomhq/ctrl/pull/8124), [#8130](https://github.com/axiomhq/ctrl/pull/8130), [#8153](https://github.com/axiomhq/ctrl/pull/8153) — "Skip all" on the getting-started page, with that module rebuilt on react-query instead of its MobX store. Heatmap zoom skips the y-axis filter when the histogram field is a backend temp name, since that name doesn't exist before the summarize. Smart filter dropdowns stay enabled when the URL still holds a selection, so you can always clear it.
- [#8107](https://github.com/axiomhq/ctrl/pull/8107), [#8118](https://github.com/axiomhq/ctrl/pull/8118), [#8106](https://github.com/axiomhq/ctrl/pull/8106) — pnpm 11: overrides and patches moved from `package.json` to `pnpm-workspace.yaml`, build scripts go through the new `allowBuilds` map. Version-scoped the TanStack zod overrides so the auth app's newer TanStack line gets zod 4. `react-scan` is opt-in behind `REACT_SCAN`.
