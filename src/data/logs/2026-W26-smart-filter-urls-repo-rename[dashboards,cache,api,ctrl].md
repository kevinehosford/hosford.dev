### Overview
Smart filter follow-ups, mostly URL edge cases from the metrics work, plus the API schema to go with it. Stopped dashboard loads from skipping the query cache. And `axiomhq/app` got renamed to `axiomhq/ctrl`.

### Highlights
- [#8022](https://github.com/axiomhq/ctrl/pull/8022), [#8038](https://github.com/axiomhq/ctrl/pull/8038) — The metrics smart filter work made URL parsing skip `parseSearchValue` for `v_*`/`vm_*` keys so empty values survive the round trip, but that also dropped JSON decoding for non-empty ones, so a saved "All" option stored as `""` came through as two literal quote characters. Narrowed the skip to the empty case. Then empty APL URL variables were overriding `declare query_parameters` defaults, so those get stripped on the APL path and MPL still sees them.
- [axiomhq/axiom#17925](https://github.com/axiomhq/axiom/pull/17925), [#8061](https://github.com/axiomhq/ctrl/pull/8061) — The dashboards API schema now models `selectType: 'query'` as its own variant with an APL or MPL payload. Legacy shapes are still validated but stay out of the public OpenAPI docs. Console resynced the generated types and collapsed its hand-rolled runtime types onto them.
- [#8082](https://github.com/axiomhq/ctrl/pull/8082) — Dashboard route loads were firing a full GET on every navigation because an earlier fix removed the cached query before calling `ensureQueryData`, so the 60s `staleTime` never applied. Went back through the cache and left invalidation at the save boundary, so clicking Edit on a dashboard that's already in memory doesn't block on a refetch.
- [#8084](https://github.com/axiomhq/ctrl/pull/8084), [axiomhq/axiom#17939](https://github.com/axiomhq/axiom/pull/17939), [axiomhq/ctrl-legacy#274](https://github.com/axiomhq/ctrl-legacy/pull/274), [axiomhq/APL#166](https://github.com/axiomhq/APL/pull/166) — Repo rename: `axiomhq/app` is now `axiomhq/ctrl`, and the old `ctrl` became `ctrl-legacy`. Updated the package name, workflow URLs and doc references across the repos that pointed at it.
