### Overview
Sign-in edge cases on the auth app: orgs that require SSO, GitHub accounts with more than one email, and password sign-in for non-production environments. On the console, two render loops and a plan downgrade banner.

### Highlights
- [#8546](https://github.com/axiomhq/ctrl/pull/8546), [#8552](https://github.com/axiomhq/ctrl/pull/8552), [#8590](https://github.com/axiomhq/ctrl/pull/8590) — When an org's WorkOS policy requires SSO and someone signs in with Google or an email code, WorkOS names the connection they should have used. The auth app now restarts the sign-in into that connection, and passes the account along so the identity provider doesn't ask them to pick it a second time. Relabelled the SAML field "Team slug", since that's what it collects.
- [#8566](https://github.com/axiomhq/ctrl/pull/8566), [#8592](https://github.com/axiomhq/ctrl/pull/8592) — GitHub only hands over the primary email, and an Axiom account can live on another address. Added a picker of their GitHub-verified addresses after sign-in, and resolve the Axiom account before the picker renders so it knows which address the account already uses. The scenario suite picked up the sign-in matrices here, one test per card.
- [#8618](https://github.com/axiomhq/ctrl/pull/8618), [#8620](https://github.com/axiomhq/ctrl/pull/8620), [#8574](https://github.com/axiomhq/ctrl/pull/8574) — Password sign-in and reset for non-production environments, mostly so agents can sign in for QA on their own. Updated the agent docs to say so, and tightened local dev so the auth app always owns its registered port.
- [#8551](https://github.com/axiomhq/ctrl/pull/8551), [#8611](https://github.com/axiomhq/ctrl/pull/8611), [#8612](https://github.com/axiomhq/ctrl/pull/8612) — Two render loops. The old `/monitors/:id` URL redirected with a render-time `<Navigate>` fed by `useLocation()`, which re-rendered itself forever. The Roles page called `normalizeRoles` during render, and that mutated MobX observables it was also reading. Stopped the mutation, then made the function generic so callers stop casting.
- [#8591](https://github.com/axiomhq/ctrl/pull/8591), [#8606](https://github.com/axiomhq/ctrl/pull/8606), [#8613](https://github.com/axiomhq/ctrl/pull/8613), [#8617](https://github.com/axiomhq/ctrl/pull/8617) — A banner for orgs on complimentary plans saying when the plan gets downgraded, with a contact sales link, behind a flag. "Wrap lines" stayed on when unchecked because Tailwind 4 puts utilities in a layer and unlayered CSS module rules beat layered ones regardless of specificity. Popovers portaled into modal sidebars take clicks again.
