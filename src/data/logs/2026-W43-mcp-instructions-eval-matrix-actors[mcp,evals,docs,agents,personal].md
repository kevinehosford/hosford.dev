### Overview
At work, shipped server instructions for the MCP server after running an eval on them. Outside work, the first full week of matrix-actors, a personal project that's days old and changing fast: 203 PRs merged in its repo this week, nearly all written by agents I direct. The repo is private, so its PR numbers below aren't links.

### Highlights
- [axiomhq/mcp#236](https://github.com/axiomhq/mcp/pull/236) — Every MCP session now gets server instructions: when to use Axiom, query rules aimed at guessed dataset and field names, and the docs tools. Ran an offline eval before shipping, 80 runs: 20 prompts, two agent clients, with and without the instructions. Claude picked the right tool on 19 of 20 prompts, up from 18, and guessed field names went from 2 to 0. Codex went from 10 to 12. The version a session received is recorded on its spans, so a session that outlives a deploy is attributed to the text it saw.
- [axiomhq/docs#773](https://github.com/axiomhq/docs/pull/773), [#10416](https://github.com/axiomhq/ctrl/pull/10416), [#10419](https://github.com/axiomhq/ctrl/pull/10419) — The docs' MCP quick setup was 15 hand-written tabs that drifted as clients changed their CLIs. Replaced them with a client picker driven by one typed data file. The console counts setup prompt copies. Loading spinners keep spinning under reduced motion.
- matrix-actors#19, matrix-actors#30 — Went through my change requests on 7 PRs the agent reviewer had already approved and turned them into four checks in the reviewer's instructions, each backed by at least three of my findings. For example: confirm the repo's check actually runs the new test, and that the fakes can reach the failing case.
- matrix-actors#73 — A bug that had been filed five times got closed on a green check that couldn't see it, because the check's environment filtering removed the variable that triggered it. Run the way the workers run them, 61 tests failed. Reopened it, and the repo's tests now run with a neutral identity.
- matrix-actors#142 — Every repo track is reviewed by a different model family from the one that built the change, and a test enforces it. Reviewers are kept off branches they built. Same-family review had been missing things I caught later.
