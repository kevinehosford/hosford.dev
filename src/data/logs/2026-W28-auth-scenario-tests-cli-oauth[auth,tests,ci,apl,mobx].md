### Overview
The auth app got a scenario test suite and CLI login. Also automated the APL language service release chain, moved bot-authored PRs onto a GitHub App, and started removing the org/user/permission MobX stores.

### Highlights
- [#8208](https://github.com/axiomhq/ctrl/pull/8208) — `apps/auth` had one placeholder test and nothing running in CI. Built a Vitest harness with fakes for WorkOS and the Axiom API that drives the real route handlers, then wrote one test per scenario: round trip, redirects, SSO landing, failure handling, the token contract. 113 tests, and they gate PRs now. One scenario had nothing behind it at all, CLI login, so added that too: OAuth authorization code with PKCE over a loopback redirect.
- [axiomhq/APL#168](https://github.com/axiomhq/APL/pull/168), [axiomhq/APL#172](https://github.com/axiomhq/APL/pull/172), [axiomhq/monaco-apl#62](https://github.com/axiomhq/monaco-apl/pull/62), [axiomhq/monaco-apl#65](https://github.com/axiomhq/monaco-apl/pull/65), [axiomhq/monaco-apl#67](https://github.com/axiomhq/monaco-apl/pull/67), [axiomhq/monaco-apl#69](https://github.com/axiomhq/monaco-apl/pull/69), [#8215](https://github.com/axiomhq/ctrl/pull/8215) — Shipped `countw`/`sumw` through language service → monaco-apl → console by hand once, then automated the chain: a release PR tags and publishes, and each hop opens the bump PR on the next repo. The first live run ran out of heap on the console lockfile install and re-fired on every push to master, so gave it more memory and guards for no-op runs and an already-open PR.
- [#8204](https://github.com/axiomhq/ctrl/pull/8204), [#8206](https://github.com/axiomhq/ctrl/pull/8206) — release-please and the scheduled update PRs are now authored by a GitHub App instead of a user account. Vercel won't deploy commits from an author outside the team, so those PRs couldn't deploy the auth app.
- [#8225](https://github.com/axiomhq/ctrl/pull/8225), [#8236](https://github.com/axiomhq/ctrl/pull/8236) — Put up the removal of `OrgStore`/`UserStatusStore`/`PermitStore`: server state moves to react-query under `entities/` and the current org comes from the `$orgId` route param instead of a store plus localStorage (it merged in August). Smart filter variables are auto-declared for APL and MPL, so autocomplete knows them and the declaration gets prepended at request time unless the query already has it.
- [#8205](https://github.com/axiomhq/ctrl/pull/8205), [#8222](https://github.com/axiomhq/ctrl/pull/8222), [#8189](https://github.com/axiomhq/ctrl/pull/8189), [#8192](https://github.com/axiomhq/ctrl/pull/8192) — Dataset extraction for edge routing uses a small Kusto-free parser, so picking the region for a query doesn't depend on having the schema loaded. Metrics heatmaps span the full requested range on the x-axis instead of stopping at the last data point. Wheel scroll works on the datetime picker inside modals, and trace IDs link again in the OTel Spans table.
